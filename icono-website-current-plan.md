# Icono Beauty World & Makeover Studio — Current Website Plan

## 1. Project Overview

**Business:** Icono Beauty World & Makeover Studio  
**Owner / Face of the Brand:** Ms. Revathy  
**Business Type:** Salon / Beauty & Makeover Studio  
**Primary Goal:** Build a premium, luxury-focused informational website that presents the salon, services, Ms. Revathy's expertise, previous work, customer trust, and drives enquiries through WhatsApp.

The website is not intended to be a full online booking platform. The appointment flow will collect enquiry details and pass them into WhatsApp for the customer to send to the salon.

---

## 2. Core Brand Direction

The overall positioning should be:

> **Luxury, premium, editorial, founder-led, elegant, modern, and trustworthy.**

The site should avoid looking like a generic beauty parlour template.

### Avoid

- Excessive pink and gold
- Glossy gradients
- Overuse of cursive fonts
- Generic beauty-template sections
- Overcrowded layouts
- Cheap-looking stock imagery
- Large grids of repetitive service cards
- Fake-looking AI salon interiors presented as real Icono photos
- Generic copy such as “Where beauty meets elegance” unless the client specifically wants it

### Aim For

- Editorial beauty/fashion composition
- Strong whitespace
- Large typography
- Restrained animation
- High-quality imagery
- Premium visual hierarchy
- Warm neutral colour balance
- Strong conversion to WhatsApp
- A clear founder story centered around Ms. Revathy

## 4. Typography Direction

Use a two-font system:

1. **Elegant editorial/display serif**
   - Main headings
   - Hero typography
   - Founder name
   - Important statements

2. **Clean modern sans-serif / grotesk**
   - Navigation
   - Paragraph text
   - Labels
   - Buttons
   - Form UI
   - Metadata

Typography should create the luxury feeling through scale, spacing, and restraint rather than decorative effects.

Exact fonts are not yet locked.

## 5. Image Strategy

The website will use three clearly separated types of imagery.

### A. Ms. Revathy — Authentic Founder Photography

Ms. Revathy is the owner and face of Icono.

Her images should be treated as important brand assets rather than repeated everywhere.

Preferred photographs if available:

- Strong editorial portrait
- Natural portrait inside or around the salon
- Close-up / alternate crop for mobile layouts

These images will primarily be used in:

- Founder section on Home
- About page
- Potential SEO/social preview assets where appropriate

### B. Previous Work / Gallery — Authentic Icono Work

The salon's actual previous work should form a premium curated portfolio.

Possible categories:

- Bridal
- Makeup
- Hair
- Styling
- Transformations
- Other confirmed services

The website should clearly distinguish this content as **real Icono work**.

### C. AI / Free / Licensed Editorial Imagery

Used for:

- Hero atmosphere
- Service storytelling
- Backgrounds
- Beauty details
- Texture
- Decorative editorial compositions

Preferred visual direction:

- Premium Indian beauty editorial
- Natural skin texture
- Soft directional/window lighting
- Warm neutral environments
- Dark hair where appropriate
- High-end makeup photography
- Hair texture/details
- Salon tools used tastefully
- Linen, glass, stone, brushed metal, dark wood
- Consistent photographic treatment
- Restrained contrast
- Shallow depth of field when suitable

Avoid generic spa-candle imagery, towel-on-head stock photos, pink cosmetic flat-lays, unrelated Western salon interiors, or obviously AI-generated imagery.

AI imagery must not be presented as if it depicts Icono's actual salon or previous work.

### 6.9 Appointment Enquiry

Reuse the proven WhatsApp-based form logic from the We Care Pets project, redesigned for Icono.

- Name
- Phone number

- Preferred date
- Preferred time
- Optional message / requirements

Important clarification near the form:

> Appointment requests are confirmed after Icono responds on WhatsApp.

This is an enquiry mechanism, not an automatic booking system.

## 13. SEO Direction

The project includes basic/on-page technical SEO foundations.

The target is to maximize discoverability for relevant local searches, but no ranking position should be guaranteed.

### Possible Search Intent Areas

Only use keywords for services the salon genuinely provides.

Examples:

- beauty salon in Kollam
- beauty parlour in Kollam
- makeover studio in Kollam
- bridal makeup in Kollam
- hair salon in Kollam
- cosmetologist in Kollam
- salon near Karicode
- beauty salon near TKM Arts College

Exact keyword targeting should be finalized after the service list is received.

### Technical SEO Checklist

- Unique page titles
- Unique meta descriptions
- Semantic HTML
- Correct heading hierarchy
- Canonical URLs
- `robots.txt`
- XML sitemap
- Open Graph metadata
- Social sharing image
- Image alt text
- Optimized images
- Responsive image sizes
- Lazy loading where appropriate
- Strong Core Web Vitals
- Mobile-first responsive implementation
- Clean internal linking
- Crawlable service descriptions
- Business name/address/phone consistency
- Google Maps integration
- Appropriate structured data

### Structured Data To Consider

Depending on the final site/content:

- LocalBusiness / BeautySalon schema
- Person schema for Ms. Revathy where appropriate
- BreadcrumbList
- Service-related structured information where valid

Structured data must accurately reflect the business and must not contain invented ratings, credentials, or claims.

### Local SEO Outside the Website

Google Business Profile will also be important for local visibility.

Recommended alignment:

- Same business name
- Same phone number
- Same address
- Correct business category
- Opening hours
- Website URL
- Real salon photos
- Customer reviews
- Service information

## 14. Performance Requirements

Luxury visuals should not make the site slow.

Priorities:

- Compress images aggressively without visible quality loss
- Prefer AVIF/WebP where practical
- Serve responsive image sizes
- Avoid unnecessarily large hero images on mobile
- Lazy-load below-the-fold media
- Limit heavy animation libraries
- Minimize JavaScript where possible
- Optimize fonts
- Prevent layout shift
- Maintain good Core Web Vitals

---

## 15. Responsive Design

Mobile must be designed intentionally rather than treated as a scaled desktop layout.

Important mobile considerations:

- Strong first-screen hero
- Readable large typography without overflow
- Simple navigation
- Easy WhatsApp access
- Touch-friendly form controls
- Gallery crops optimized independently from desktop
- Founder portrait adapted for mobile
- Avoid excessive animation
- Keep conversion CTAs accessible

---

## 16. Motion Direction

Animation should feel premium and restrained.

Potential effects:

- Soft image reveal
- Subtle fade/translate on scroll
- Slow editorial image scaling
- Text mask/reveal where tasteful
- Underline/button transitions
- Gallery hover zoom on desktop

Avoid:

- Excessive parallax
- Constant floating elements
- Bouncy interactions
- Large cursor gimmicks
- Over-animation that harms mobile performance

## 21. Stitch Design Workflow

Do not generate every screen independently without a shared system.

Recommended order:

1. Lock brand direction.
2. Lock typography.
3. Lock colour usage.
4. Create desktop Home concept in Stitch.
5. Refine until the visual language is correct.
6. Establish reusable patterns:
   - Navbar
   - Buttons
   - Labels
   - Image treatment
   - Section spacing
   - Founder block
   - Service presentation
   - Review component
   - Forms
   - Footer
7. Generate remaining pages using the same system.
8. Design mobile versions intentionally.
9. Export/use Stitch output as visual and implementation reference.
10. Rebuild cleanly in the actual project rather than blindly accepting generated code.
